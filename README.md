# 数字信号处理课程设计 · FIR 数字滤波器的 FPGA 实现

MATLAB 完成 **61 阶线性相位 FIR 低通滤波器**设计并做 **12 bit 系数量化**；采用线性相位对称结构，将乘法器数量由 61 个减少到 **31 个**，降低硬件资源占用；基于 Quartus II + ModelSim 完成 RTL 综合与仿真验证。

## 技术栈
- MATLAB：滤波器设计与频响验证、系数量化
- Verilog / VHDL、Quartus II、ModelSim
